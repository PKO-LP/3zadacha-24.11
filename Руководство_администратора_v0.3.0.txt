Программа: Приём заявок
Документ для версии: 0.3.0
Автор / команда: Команда № 1 (Ананьев Александр, группа 12ТЭС)
Дата проверки: 24.11.2026

1. Назначение
Программа предназначена для учёта поступающих заявок (до 10 штук), фиксации времени их принятия, смены статусов и подсчёта закрытых заявок. Администратор должен уметь разворачивать обновление, проверять его работоспособность и выполнять откат к версии 0.2.1 при сбоях.

2. Условия запуска
На компьютере должен быть установлен Python 3 со стандартными библиотеками tkinter и datetime. Для корректного запуска в одной папке должны находиться исполняемый файл программы app_v03_обновление.py и файл изображения логотипа logo.png.

3. Запуск рабочей версии
Запускать нужно файл app_v03_обновление.py. Для запуска в операционной системе откройте папку с файлами и дважды щёлкните по файлу программы левой кнопкой мыши (либо откройте через IDLE или VS Code и нажмите F5). Убедиться, что запущена нужная версия, можно по заголовку окна «Приём заявок 0.3.0» и серой надписи «Версия 0.3.0» в нижней части окна.

4. Проверка после обновления
Действие 1: Нажать кнопку «Принять заявку».
Ожидаемый результат: Счётчик заявок увеличился на 1, в строке «Принято» отобразились текущие дата и время.
Действие 2: Нажимать кнопку «Сменить статус» до перехода в статус «Готово».
Ожидаемый результат: Статусы меняются по порядку (Новая, В работе, Готово), при выборе «Готово» счётчик «Закрыто заявок» увеличивается на 1.
Действие 3: Нажать кнопку «Сбросить».
Ожидаемый результат: Счётчики принятых и закрытых заявок обнуляются, дата сбрасывается на прочерк.

5. Сохранность данных
После закрытия программы данные не сохраняются, так как запись в файл или базу данных не предусмотрена. Перед завершением работы или заменой файлов на новую версию нужно предупредить пользователей, что все текущие счётчики сбросятся.

6. Резервная копия и откат
Для возврата сохраняется предыдущая версия 0.2.1, её резервная копия (app_v021_backup.py или app_текущая_v0.2.1.py) хранится в той же рабочей папке. Откат потребуется, если версия 0.3.0 не запускается, зависает или некорректно считает заявки. Для возврата нужно закрыть окно версии 0.3.0, запустить резервный файл версии 0.2.1 и убедиться, что в заголовке и внизу окна отсутствует надпись «0.3.0». Фактическое время пробного отката составило 2 минуты.

7. Неисправности и помощь
Возможная проблема: программа не запускается и закрывается с ошибкой. Способ проверки: запустить файл через терминал или редактор кода, чтобы увидеть текст ошибки (чаще всего отсутствует файл logo.png рядом со скриптом). Дальнейшее действие: поместить logo.png в одну папку с программой и повторить запуск. Если проблему решить не удалось, обратиться к разработчику Команды № 1 (Ананьеву Александру, стол № 3).
